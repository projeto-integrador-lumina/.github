# Projeto Lumina — Lolá: Gamificando a Fala

Plataforma de apoio fonoaudiológico voltada ao tratamento de crianças com desvio fonológico. O sistema integra um Painel Administrativo para acompanhamento clínico da fonoaudióloga e uma aplicação web gamificada (PWA) para realização dos exercícios de fala dos pacientes.

## Taxonomia Padronizada de Etiquetas (Labels)

A gestão e classificação das issues seguem a estrutura de categorias abaixo:

| Categoria | Etiquetas Obrigatórias | Finalidade |
| :--- | :--- | :--- |
| **Hierarquia** | `epic` | Identifica iniciativas e pacotes macro de entrega. |
| **Frentes Técnicas** | `backend`, `frontend`, `database`, `ui` | Identifica as camadas e especialidades envolvidas. |
| **Tipagem** | `documentation`, `bug`, `enhancement` | Classifica a natureza da exigência. |
| **Prioridade** | `priority: high`, `priority: medium`, `priority: low` | Sinaliza o nível de urgência e valor de negócio. |

## Estrutura de Repositórios da Organização

A organização possui os seguintes repositórios estruturados para o ecossistema da solução:

* **`.github`:** Configurações globais da organização e documentação de perfil.
* **`lumina-frontend`:** Código-fonte da interface do Painel Administrativo e do PWA Gamificado construídos com Tailwind CSS.
* **`lumina-backend`:** Serviços de API RESTful em Node.js, controlo de acesso e regras de negócio.
* **`lumina_documentacao`:** Documentação técnica, requisitos e diagramas arquiteturais da solução.
* **`lumina-design`:** Ativos gráficos, protótipos visuais e guias de identidade visual da plataforma Lolá.
* **`lumina-artigo`:** Artigo científico e relatórios académicos do projeto.
