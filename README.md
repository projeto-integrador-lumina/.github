# Projeto Lumina — Lolá: Gamificando a Fala

Plataforma de apoio fonoaudiológico voltada ao tratamento de crianças com desvio fonológico. O sistema integra um Painel Administrativo para acompanhamento clínico da fonoaudióloga e uma aplicação web gamificada (PWA) para realização dos exercícios de fala dos pacientes.

## Estrutura de Repositórios da Organização

A organização possui os seguintes repositórios estruturados para o ecossistema da solução[cite: 13]:

* **`.github`:** Configurações globais da organização e documentação de perfil[cite: 13].
